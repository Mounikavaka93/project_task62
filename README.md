# Halden

A simulated trading and investment desk built with React, Vite, and Tailwind CSS. Quotes are sample figures. Orders stay in the browser.

## Scripts

```bash
npm install
npm run dev
npm run build
```

Open the local URL Vite prints. The home page includes the market overview, stocks, portfolio, watchlist, order ticket, news, and the reasons to use the desk. Login accepts any email and a password of at least 8 characters.
